# CI/CD

This project demonstrates a CI/CD workflow for a small Node.js API. The app includes tests and lint checks, a Dockerfile, and Kubernetes deployment and service manifests.

## Contents

- `app/` — application source and tests
- `kubernetes/` — deployment and service manifests
- `screenshots/` — project evidence screenshots

Run the app checks from `app/` with `npm test` and `npm run lint`.
